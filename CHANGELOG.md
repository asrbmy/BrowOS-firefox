# Changelog

## Unreleased

- New apps: To-Do, Pomodoro, Weather, Music, Terminal, Recycle Bin, Snake, Minesweeper, Tetris
- Virtual desktops, window snapping, customizable keyboard shortcuts
- Notifications with Do Not Disturb, system tray and quick settings
- Start menu search
- Desktop widgets and sticky notes
- Lock screen with optional PIN, screensaver, theme packs
- Recycle Bin for removed apps and shortcuts
- Export / import backup
- New apps: Kanban, Converter, Password Generator, Typing Test
- Apps now receive keyboard focus when opened
- Files: file manager with folders, upload, drag and drop, trash and search; images, PDFs and text open in the viewers and editor
- Calendar with repeating events and reminders
- Image Viewer, PDF Viewer, Code Editor, Notes manager, Habits, Budget, Bookmarks (optional permission), Recorder
- Games: Chess (with a computer opponent), Sudoku, Solitaire, Orb Hop
- Window switcher (Alt + J), Task View, command palette, clipboard history
- Profiles, sync through the browser account, wallpaper slideshow, tour for new users
- SDK for websites in a BrowOS window, with per-app permissions
- Accessibility: focus rings, window roles, reduce motion, high contrast pack
- Firefox manifest and build script (untested), browser tests in `tests/`

## 1.0.0

First public beta.

- Desktop with draggable windows, taskbar, Start menu and right-click menus
- Apps: Notepad, Calculator, Clock, Paint, Browser, Task Manager
- BrowStore: Discover, BrowOS Apps, Library, add any website
- Floating windows for sites that can't be embedded
- Personalization: wallpapers, accent color, theme, corners, window buttons, transparency, cursor
- Update reminder for manual installs
